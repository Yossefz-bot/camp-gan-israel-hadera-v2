שדרוג סטטיסטיקות מתקדם V24 — קעמפ גן ישראל חדרה

מה נוסף
========
- מבקרים ייחודיים, ביקורים וצפיות בעמודים — כל אחד בנפרד.
- מבקרים חוזרים ושיעור יציאה מהירה.
- זמן פעיל אמיתי וממוצע לביקור.
- ביצועים לכל עמוד: מבקרים, ביקורים, צפיות, זמן, גלילה ויציאה מהירה.
- פילוח לפי מקור כניסה ולפי סוג מכשיר.
- מעקב סרטונים: התחלה, 25%, 50%, 75%, סיום וזמן צפייה.
- מעקב המנונים: הפעלות, סיומים וזמן האזנה.
- מעקב גלריות: פתיחות, פריטים שנצפו, השלמות, הורדות, מועדפים ושיתופים.
- השוואה אוטומטית לתקופה הקודמת.
- תובנות מהירות וחיבורים פעילים בזמן אמת.
- מכשירי ניהול אינם נספרים, גם בצד הדפדפן וגם בצד השרת.

פרטיות
======
המערכת אינה שומרת שם, מספר טלפון או כתובת IP בתוך טבלאות הסטטיסטיקה.
מבקר מזוהה באמצעות מזהה אקראי שנשמר בדפדפן בלבד.

Migration
=========
יש להריץ פעם אחת ב-D1 Console את:
migrations/0005_analytics_v24.sql

הקוד גם מנסה ליצור את הטבלאות אוטומטית, אבל מומלץ להריץ את קובץ ה-Migration כדי לוודא שהכול מוכן לפני כניסת המבקרים.

נתונים ישנים
============
הנתונים הישנים נשארים בטבלת analytics_daily ומופיעים במסך כ"צפיות שנשמרו במערכת הישנה".
המדדים המפורטים מתחילים להיאסף מרגע פריסת V24.
לאיפוס מלא ניתן להריץ את optional/RESET-ANALYTICS-V24.sql.

החרגת מכשיר שלך
================
היכנס פעם אחת למערכת הניהול מכל טלפון או מחשב שברצונך להחריג.
הדפדפן יסומן אוטומטית ולא ישלח נתוני סטטיסטיקה.
