עדכון V12.1 — WhatsApp ומחיקה מרוכזת של מדיה
================================================

מה נוסף
-------
1. בפניות מהאתר אפשר ללחוץ "השב ב־WhatsApp".
   המערכת פותחת צ׳אט עם מספר הפונה והודעה מוכנה. השליחה עצמה מתבצעת ידנית בתוך WhatsApp.

2. מסך "ניוזלטר" הוחלף ב"תפוצת WhatsApp".
   אפשר:
   - לכתוב הודעה ולהוסיף קישור.
   - להעתיק את ההודעה.
   - להעתיק את כל המספרים.
   - להוריד קובץ CSV של אנשי הקשר.
   - לעבור נמען־נמען ולפתוח את הצ׳אט המתאים.

3. במדיה והעלאות אפשר לבחור כמה קבצים וללחוץ "מחיקת הנבחרים".
   המחיקה מסירה את הקבצים ממסד הנתונים ומ־R2, ומנקה הפניות אליהם מתמונות שער, מצגת דף הבית והגדרות האתר.

4. מספר טלפון הוא שדה חובה בטופס הפנייה, כדי שאפשר יהיה לחזור לפונה ב־WhatsApp.

התקנה
------
1. העתק את תוכן חבילת התיקון לתיקיית המאגר ואשר החלפה.
2. ב־GitHub Desktop בצע Commit בשם:
   Add WhatsApp tools and bulk media delete
3. לחץ Push origin.
4. המתן ל־Success ב־Cloudflare.
5. רענן את הניהול עם Ctrl+F5.

לא צריך להריץ SQL.
לא צריך Resend, API Key או משתנים חדשים ב־Cloudflare.

הערה חשובה
-----------
המערכת אינה שולחת הודעות WhatsApp אוטומטית. היא פותחת כל צ׳אט עם ההודעה מוכנה, ואתה מאשר את השליחה בתוך WhatsApp. כך אין צורך ב־WhatsApp Business API.
