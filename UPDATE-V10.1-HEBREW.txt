עדכון V10.1 — ייבוא רשימת תפוצה מאקסל
========================================

מה נוסף:
- כפתור "ייבוא מאקסל" במסך נרשמים לעדכונים.
- תמיכה בקבצי XLSX, XLS ו-CSV.
- זיהוי אוטומטי של עמודות אימייל, שם וטלפון בעברית ובאנגלית.
- תצוגה מקדימה לפני הייבוא.
- דילוג על שורות ללא אימייל תקין ועל כפילויות בתוך הקובץ.
- עדכון נרשמים קיימים במקום יצירת כפילויות.
- אפשרות להפעיל מחדש כתובות שהוסרו בעבר.
- פס התקדמות וסיכום תוצאות.

אין צורך להריץ SQL ואין שינוי במבנה מסד הנתונים.

התקנה דרך GitHub Desktop:
1. חלץ את קובץ ה-ZIP.
2. לחץ Show in Explorer במאגר camp-gan-israel-hadera-v2.
3. העתק את כל תוכן התיקייה שחולצה לתוך המאגר ובחר Replace.
4. ב-GitHub Desktop כתוב Summary: Add Excel mailing list import
5. לחץ Commit to main ולאחר מכן Push origin.
6. המתן לפריסה ירוקה ב-Cloudflare.
7. פתח את הניהול, בצע Ctrl+F5, ועבור אל "נרשמים לעדכונים".
