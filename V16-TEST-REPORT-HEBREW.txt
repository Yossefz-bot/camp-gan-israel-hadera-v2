דוח בדיקות V16
===============

תוקנו:
- קריסת אתחול הניהול עקב ארבע פעולות מדיה מרוכזות שהופעלו ללא פונקציות קיימות.
- כפתור עריכה במדיה האחרונה בלוח הבקרה שהפנה לפונקציה חסרה.
- שמירת הגדרות: מצב טעינה, מניעת לחיצה כפולה, הודעת הצלחה/כישלון ובדיקת קישורים.
- שמירת עריכת מדיה, מחיקה, תמונת שער וסרטון סיכום עם טיפול בשגיאות.
- פעולות מרוכזות: פרסום, טיוטה, ארכיון, העברה ליום, קטגוריה ומחיקה.
- ניקוי הפניות לסרטון סיכום בעת העברה, טיוטה, ארכיון או מחיקה.
- כפתור חדש להגדרת סרטון כ"סרטון סיכום היום".
- הפרדת סרטון הסיכום מהגלריה בצד השרת, כולל זיהוי אוטומטי של הסרטון הראשון כשלא נבחר סרטון מפורש.
- אחידות גרסאות המטמון והנכסים ל־16.0.0.
- ניקוי כללי CSS סותרים שהצטברו בגרסאות קודמות.
- שמירת קישורי הכפתורים מהניהול והצגתם באתר.

בדיקות שבוצעו:
- npm run check — עבר.
- בדיקת תחביר לכל קובצי JavaScript ו־Pages Functions — עברה.
- בדיקת Chromium מקומית למערכת הניהול — כל 11 המסכים נטענו.
- בדיקת עריכת מדיה ושמירתה — עברה.
- בדיקת הגדרת סרטון סיכום — עברה.
- בדיקת שמירת הגדרות וקישור הרשמה — עברה.
- בדיקת טופס הרשמה ציבורי — עברה.
- בדיקת גלריית יום: סרטון למעלה, ללא כפילות ברשת, לב ב־hover — עברה.
- בדיקת סכמת SQLite של 0000 + 0003 — עברה.
- בדיקת API של גלריית יום עם סרטון fallback — עברה.

הערה:
הבדיקות בוצעו על המאגר המלא שהועלה ועל סביבת דפדפן מקומית עם תשובות API מדומות. בדיקת הכתובות החיות מבחוץ לא התאפשרה מסביבת העבודה, ולכן לאחר הפריסה יש לבצע בדיקת קבלה קצרה בדומיין האמיתי.
