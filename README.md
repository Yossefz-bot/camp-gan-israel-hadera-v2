# Camp Gan Israel Hadera — V16

האתר הציבורי ומערכת הניהול של קעמפ גן ישראל חדרה על Cloudflare Pages, Pages Functions, D1 ו־R2.

## החיבורים הקיימים

- D1 binding: `DB`
- R2 binding: `MEDIA`
- Build output directory: `public`
- Production branch: `main`

## בדיקה לפני פריסה

```bash
npm install
npm run check
```

הוראות הפריסה נמצאות בקובץ `START-HERE-HEBREW.md`.
